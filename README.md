# jp-office-tools — 日本の業務環境向け 汎用オフィスツール(Claude Code プラグイン)

日本のオフィス業務でよくある作業(Excel/CSVの整形・比較、議事録や稟議書などのビジネス文書作成、祝日・営業日・和暦の計算)を支援する、**汎用**のスキル＋コマンド集です。

> **汎用・公開情報のみ**：本プラグインは一般的な業務知識・公開されている祝日データ等のみで構成され、**特定企業の固有情報(社名・内部様式・実際の契約内容など)は一切含みません**。ただし実際の利用時には**社内データを扱うことになるため、必ず所属組織のAI利用ポリシーに従って使用してください**。

---

## 含まれるもの

| 種類 | 内容 |
|---|---|
| **スキル** `jp-excel` | Excel/CSVの文字コード判別・変換(Shift-JIS/CP932/UTF-8)、全角半角・和暦日付の正規化、ファイル比較(diff。xlsxは全シート対応・シート単位)、クロス集計(pivot)・グラフ生成(chart) |
| **スキル** `jp-bizdoc` | 議事録・稟議書・報告書のテンプレート、メールの敬語添削、スライド構成案、ビジネス文書の翻訳、PDFの読み取り・要約・表抽出(CSV/Excel保存)、表記ゆれの検出・用語集作成 |
| **スキル** `jp-mail` | ビジネスメールの作成・返信・定型文(依頼/お礼/お詫び/催促/報告/断り × 格式度3段)・日程調整 |
| **スキル** `jp-slides` | プレゼン資料(`.pptx`)の生成 — 16テーマそれぞれ固有のモダンデザイン(ベントー型ダッシュボード/オーバーサイズポスター/オーガニックウェーブ/ダークガラス 等)を持つビジュアルエンジン、KPI・指標を見せる統計(stats)スライド、アクセント色・フォント・ライト/ダークのカスタマイズ、社内ブランドテンプレートの活用、全テーマ見本(gallery/overview)出力 |
| **スキル** `jp-dates` | 祝日判定・営業日計算(◯営業日後/前)・和暦⇔西暦変換・年度計算 |
| **コマンド** | `/xl-clean`(Excel/CSVクレンジング)・`/xl-diff`(差分比較)・`/xl-pivot`(クロス集計)・`/xl-chart`(グラフ生成)・`/giji`(議事録生成)・`/ringi`(稟議書下書き)・`/mail`(メール作成・返信)・`/keigo`(敬語添削)・`/slides`(スライド生成)・`/pdf-table`(PDF表抽出)・`/glossary`(表記ゆれ検出・用語集作成)・`/jp-office-setup`(実行環境点検) |

## 前提

- **Claude Code**(CLI / デスクトップ / IDE拡張のいずれか)
- (任意)**Python 3.10+** … `jp-excel`(Excel/CSVのクレンジング・diff)、`jp-dates`(祝日・営業日・和暦の計算)、`jp-bizdoc` の PDF テキスト抽出、`jp-slides`(スライド `.pptx` 生成)で必要です。
- **`jp-bizdoc` の文書作成系機能(議事録・稟議書・報告書・敬語添削・スライド構成案・翻訳)はPythonが無くてもすべて動作します。**Pythonが必要になるのは、上記のスクリプトを伴う機能(`jp-slides` の実際の `.pptx` 生成を含む)のみです。

## インストール(Claude Code)

Claude Codeの中で以下を実行します(**GitHub認証不要**の公開マーケットプレイスです)。

```
/plugin marketplace add muji-j/jp-office-tools
/plugin install jp-office@jp-office-tools
```

- 1行目でこのマーケットプレイスを登録し、2行目でプラグインを導入します(`/plugin` メニューから一覧で選んで導入も可)。
- Python・ライブラリが不足している場合は `/jp-office-setup` を実行すると、確認のうえで導入を案内します。

### 更新

```
/plugin marketplace update
/plugin install jp-office@jp-office-tools
```

(作者がバージョンを上げて公開すると、上記で最新化されます。変更内容は `CHANGELOG.md` を参照。)

### 自動更新(おすすめ)

新バージョンを公開したとき、**導入済みの環境が起動時に自動で最新化**されるようにできます(自動更新は各利用者側の設定です)。次のどちらかで有効化します。

- **かんたん**: `/plugin` を開き、**Marketplaces タブ → `jp-office-tools` → 自動更新を有効化**。
- **設定で一括(自動インストール＋自動更新)**: 各自の `~/.claude/settings.json` に次を追記(既存設定にマージ):

  ```json
  {
    "extraKnownMarketplaces": {
      "jp-office-tools": {
        "source": { "source": "github", "repo": "muji-j/jp-office-tools" },
        "autoUpdate": true
      }
    },
    "enabledPlugins": {
      "jp-office@jp-office-tools": true
    }
  }
  ```

  → これだけで**インストールも自動**になり、以後は起動時に自動更新されます(更新後に `/reload-plugins` の案内が出ることがあります)。

> 注: 公開マーケットプレイスでは配布者から更新を強制できません(自動更新は利用者側の設定)。組織で一括強制する場合は、管理設定(managed settings)に上記と同じ内容を設定します。

## 使い方の例

- `/xl-clean 売上.csv` … 文字コードを判別したうえでクレンジング(全角半角・和暦・空白の正規化)を行い、別名コピーとレポートを出力
- `/xl-pivot 売上.csv` … 列名を指定しなくても列構造を見て集計軸・集計値を提案し、クロス集計の表とCSVを出力
- `/xl-chart 売上.csv` … 列構造から x軸・y軸・グラフ種類を提案し、折れ線/棒/円グラフをPNGまたはHTMLで生成
- `/giji` … 会議メモや文字起こしを貼り付けると、決定事項・宿題事項(担当・期限)を整理した議事録を生成
- `/mail` … 受信メールの貼り付けまたは用件を伝えると、関係(社外フォーマル/社外標準/社内)とトーンを確認したうえで返信・新規メールの文面を作成
- `/slides` … 「月次報告のスライドを作って」のように伝えると、構成(結論先行型/経緯報告型/比較検討型)とテーマを推定し、内蔵16テーマから`.pptx`を生成(テーマ・アクセント色・フォント・社内ブランドテンプレートを指定する精密経路にも対応)
- `/pdf-table 資料.pdf` … PDF内の表をマークダウン表で表示。件数が多ければCSV・Excel(xlsx)への保存も選べる
- `/glossary` … 文書を渡すと表記ゆれ(サーバー/サーバ、Ｗｅｂ/Web 等)の統一案を提示。頻出用語から用語集の下書きも作成
- 「来月10日の5営業日前は?」のように尋ねると、`jp-dates` スキルが自動的に参照され、実日付で回答
