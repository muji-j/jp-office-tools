# jp-dates — 日本の日付ユーティリティ

日付の計算は暗算せず、必ずスクリプト `${CLAUDE_PLUGIN_ROOT}/scripts/jp_dates.py` を実行して答える。
祝日は `jpholiday` ライブラリ(内閣府公表データ準拠)に基づく。

## 使い方

| 目的 | コマンド | 出力例 |
|---|---|---|
| 祝日判定 | `python "${CLAUDE_PLUGIN_ROOT}/scripts/jp_dates.py" holiday 2026-01-01` | `元日` |
| N営業日後(前) | `python "${CLAUDE_PLUGIN_ROOT}/scripts/jp_dates.py" addbiz 2026-07-17 1` | `2026-07-21` |
| 年末年始も除外 | `... addbiz 2026-12-28 1 --exclude-yearend` | `2027-01-04` |
| 和暦→西暦 | `... wareki R6.4.1` | `2024-04-01` |
| 年度 | `... fy 2026-03-31` | `2025` |

## 鉄則

1. **営業日 = 土日+祝日を除く平日**。年末年始(12/29〜1/3)を休業とするかは組織の慣行 — указ가 없으면 「年末年始を営業日に含めるか」を確認するか、両方の結果を併記する。
2. 祝日データはライブラリ更新に依存する。**遠い将来の日付**(祝日法改正の可能性)は断定せず「現行法令ベース」と付記する。
3. 和暦の元年表記(令和元年)と1年表記は同義。略記(R6.4.1 / H31.1.4)も受け付ける。
4. Python が無い環境では計算せず、`/jp-office-setup` を案内する。
