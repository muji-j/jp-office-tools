# jp-mail 定型文ツールキット

用件別に書き出し・結びを複数案そろえ、画一化を避けるためのリファレンス。敬語の正確さは
[keigo.md](../../jp-bizdoc/references/keigo.md)、AI っぽさの回避は [anti-ai.md](../../jp-bizdoc/references/anti-ai.md) を必ず併用する。

## 格式度 3段

| 格式度 | 想定する相手 | 特徴 |
|---|---|---|
| 社外フォーマル | 初対面の相手・公式な案内状・儀礼文書 | 「お世話になっております」に加え名乗りを丁寧に。依頼・断りには必ずクッション言葉。格式を要する文書では時候の挨拶を添える(下記参照)。 |
| 社外標準 | 継続的に取引のある相手・平常のやり取り | 「お世話になっております」で開始。要旨は早めに示し、クッション言葉は依頼・断り・催促の直前に一つ添えれば足りる。本ツールキットの各定型は原則この水準を基準に示す。 |
| 社内 | 同僚・上司・カジュアルな間柄 | 挨拶を省略し名乗り・要旨から始めてよい。結びも簡潔に(「よろしくお願いします」程度)。上司・他部署宛など格式を要する相手には社外標準に近づける。 |

時候の挨拶は社外フォーマルなど**格式を要する場面のみ**で使う。通常の社外標準・社内メールには付けない
([keigo.md](../../jp-bizdoc/references/keigo.md) の12ヶ月表と整合)。

## メールの基本構成

```
宛名 → 書き出し → 用件(結論先行) → 詳細 → 結び → 署名
```

- 宛名: 会社名・部署名・役職+氏名+「様」の順(役職と「様」は重ねない)。社内はチャット的に「◯◯さん」のみでもよい。
- 書き出し: 挨拶+名乗り。関係・頻度・直近のやり取りの有無で変える(下記の用件別定型・[anti-ai.md](../../jp-bizdoc/references/anti-ai.md) #1参照)。
- 用件: 結論・要旨を先に一文で示してから詳細に入る(#5 結論後回し回避)。
- 詳細: 背景・理由・依頼内容・期限などを具体的に。
- 結び: 用件の性質(依頼/報告/断り等)に応じた一文。画一的な「何卒よろしくお願い申し上げます」だけで済ませない。
- 署名: 会社名・部署名・氏名・連絡先。

## 用件別定型(6種)

各定型は社外標準を基準に示す。社外フォーマルはクッション言葉・敬語をより厚めに、社内はより簡潔にする
(格式度の使い分けは上表を参照)。

### 1. 依頼

**書き出し(複数案)**
- 「お世話になっております。◯◯部の△△です。」(通常)
- 「先日はお時間をいただきありがとうございました。」(直前にやり取りがあった相手への依頼)
- 「初めてご連絡いたします。◯◯部の△△と申します。」(初回)

**本文骨子**
1. 結論: 何を依頼したいかを一文で(例:「◯◯の件で、資料のご提供をお願いできますでしょうか。」)
2. 背景・理由を簡潔に添える(依頼の必然性が伝わる程度)。
3. 具体的な依頼内容・期限・方法を箇条書きまたは短い段落で示す。
4. クッション言葉を添えて依頼文を締める(「お忙しいところ恐縮ですが」「差し支えなければ」等)。

**結び(複数案)**
- 「ご検討のほど、よろしくお願いいたします。」
- 「お手数をおかけしますが、◯月◯日までにご返信いただけますと幸いです。」
- 「ご不明点があれば遠慮なくお知らせください。」

**AIっぽくしないコツ**: 依頼の理由を一般論("業務の都合上"等)で済ませず、具体的な事情を一言添えると機械的な印象が薄れる([anti-ai.md](../../jp-bizdoc/references/anti-ai.md) #6参照)。

### 2. お礼

**書き出し(複数案)**
- 「本日はお時間をいただき、ありがとうございました。」(面談・打ち合わせ後)
- 「早速のご対応をいただき、ありがとうございます。」(依頼への迅速な対応への礼)
- 「先日はご丁寧にご説明いただき、ありがとうございました。」

**本文骨子**
1. 何についての礼かを具体的に述べる(単に「ありがとうございます」で終わらせない)。
2. 得られた成果・印象・今後への手応えを一言添える(例:「特に◯◯の点、大変参考になりました。」)。
3. 次のアクションがあれば触れる(次回打ち合わせ日程・対応予定など)。

**結び(複数案)**
- 「今後ともどうぞよろしくお願いいたします。」
- 「引き続きご指導のほどお願い申し上げます。」
- 「取り急ぎお礼まで申し上げます。」

**AIっぽくしないコツ**: 「ありがとうございます」を段落末に反射的に繰り返さず、一通の中で本当に伝えたい箇所に絞る([anti-ai.md](../../jp-bizdoc/references/anti-ai.md) #8参照)。

### 3. お詫び

**書き出し(複数案)**
- 「この度はご迷惑をおかけし、誠に申し訳ございませんでした。」(明確な不手際があった場合)
- 「ご連絡が遅くなりましたこと、お詫び申し上げます。」(遅延のみの場合)
- 「先ほどお送りした資料に誤りがございました。」(訂正を伴う軽微な詫び)

**本文骨子**
1. 何について詫びるのかを具体的に一文で示す(対象を曖昧にしない)。
2. 発生した事実・原因を簡潔に説明する(言い訳に終始しない)。
3. 再発防止・是正策、または訂正内容を明示する。
4. 相手への影響への配慮を一言添える。

**結び(複数案)**
- 「今後このようなことがないよう十分注意いたします。」
- 「改めてご迷惑をおかけしましたことをお詫び申し上げます。」
- 「ご不便をおかけしますが、何卒ご容赦くださいますようお願い申し上げます。」

**AIっぽくしないコツ**: 「大変申し訳ございませんでした」を軽微な件にも一律で使わず、事案の重さに応じて言葉の強さを変える([anti-ai.md](../../jp-bizdoc/references/anti-ai.md) #8参照)。

### 4. 催促

**書き出し(複数案)**
- 「先日ご連絡いたしました◯◯の件、その後いかがでしょうか。」
- 「たびたびのご連絡で恐縮ですが、◯◯の件でご連絡いたしました。」
- 「◯月◯日にお送りした件、ご確認いただけておりますでしょうか。」

**本文骨子**
1. 何を待っている状態なのかを客観的に示す(相手を責める語調にしない)。
2. 元の依頼内容・期限を簡潔に再掲する(相手が探さずに済むように)。
3. 状況によっては期限の延長や代替案の余地があることも添える。
4. クッション言葉を前置きしてから改めての依頼を伝える。

**結び(複数案)**
- 「お忙しいところ恐縮ですが、ご確認いただけますと幸いです。」
- 「ご都合が悪い場合はお知らせいただければ調整いたします。」
- 「お手数をおかけしますが、◯日頃までにご一報いただけますでしょうか。」

**AIっぽくしないコツ**: 催促と非難は違う。「〜のはずですが」のような詰問調を避け、相手側の事情も配慮した一文を混ぜると自然になる。

### 5. 報告・連絡

**書き出し(複数案)**
- 「◯◯の件についてご報告いたします。」
- 「表題の件、進捗をご連絡いたします。」
- 「取り急ぎ、◯◯についてご連絡いたします。」(速報性を優先する場合)

**本文骨子**
1. 結論・現状を先に一文で示す(進んでいるか、完了したか、課題があるか)。
2. 具体的な事実・数字を挙げる(抽象的な言い回しだけで終わらせない)。
3. 今後の予定・次のアクションがあれば明記する。
4. 判断や対応が必要な事項があれば、その旨を明確に区別して伝える。

**結び(複数案)**
- 「まずはご報告まで。」
- 「何かご不明な点がございましたらお知らせください。」
- 「引き続き進捗があり次第ご連絡いたします。」

**AIっぽくしないコツ**: 並列する事実をすべて同じ文型・同じ長さで揃えず、長短を混ぜる(例:「資料を確認し、課題を洗い出した。次は対応方針を詰める。」)([anti-ai.md](../../jp-bizdoc/references/anti-ai.md) #7参照)。

### 6. 断り

**書き出し(複数案)**
- 「ご連絡いただきありがとうございます。」(依頼・提案への謝意から入る)
- 「せっかくのお話ですが」(口頭寄りの柔らかい入り、メールでも使用可)
- 「ご期待に沿えず恐縮ですが」

**本文骨子**
1. まず検討・提案への感謝を述べる(いきなり否定形から入らない)。
2. 断る理由を無理のない範囲で簡潔に説明する(詳細な内部事情まで開示する必要はない)。
3. 断る旨を明確に伝える(曖昧なまま濁さない)。
4. 代替案・別の形での協力可能性があれば添える(関係維持につながる)。

**結び(複数案)**
- 「またの機会がございましたら、ぜひよろしくお願いいたします。」
- 「今回は見送らせていただきますが、引き続きどうぞよろしくお願いいたします。」
- 「ご期待に沿えず申し訳ございませんが、何卒ご理解のほどお願い申し上げます。」

**AIっぽくしないコツ**: 断りの結論を曖昧な婉曲表現だけで濁さない。クッション言葉で配慮を示しつつも、「今回は見送らせていただきます」のように結論ははっきり書く([anti-ai.md](../../jp-bizdoc/references/anti-ai.md) #5参照)。
