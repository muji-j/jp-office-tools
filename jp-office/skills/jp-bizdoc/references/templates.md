# jp-bizdoc 文書テンプレート集

議事録・稟議書・報告書の3種について、そのまま使えるひな形を示す。項目名・並び順はここに合わせる。
依頼者の指定で項目を減らす場合も、まず本テンプレートを提示したうえで「どの項目を省略するか」を確認する。

## 1. 議事録

会議名・日時・場所・出席者(敬称・所属つき)・欠席者・議題・決定事項(番号付き)・宿題事項(内容/担当/期限の表)・
次回予定・特記事項の順で構成する。

**宿題事項の期限が発言・資料から読み取れない場合は、期限欄を空欄のまま埋めず「要確認」と明記する。**
「おそらく今月中」のような推測での補完はしない。期限を営業日ベースで計算する必要がある場合(例:「3営業日後まで」)は
`jp-dates` スキルに委ねる。

```markdown
# 議事録

- 会議名: ◯◯定例会議
- 日時: 2026年◯月◯日(◯) 10:00〜11:00
- 場所: 本社3階会議室(オンライン参加可・会議URLは別途共有)
- 出席者: 株式会社サンプル 営業部長 山田太郎 様、企画部 佐藤花子
- 欠席者: なし
- 議題:
  1. ◯◯の進捗確認
  2. ◯◯の方針検討
- 決定事項:
  1. ◯◯案を正式採用する。
  2. 次回までに見積を再提出する。
- 宿題事項:

  | 内容 | 担当 | 期限 |
  |---|---|---|
  | 見積書の再提出 | 佐藤花子 | 要確認(次回会議で確定予定) |
  | 議事録の共有 | 事務局 | 本日中 |

- 次回予定: 2026年◯月◯日(◯) 同時刻
- 特記事項: なし
```

## 2. 稟議書

件名・起案部署/起案者・起案日・決裁区分・起案理由(背景)・内容(何を・いくらで・いつまで)・
金額(税込・内訳)・効果(定量・定性)・リスクと対策・添付資料の順で構成する。

- 「内容」は必ず**何を・いくらで・いつまでに**の3点を明示する。いずれかが未定のまま起案しない。
- 「金額」は税込金額を主とし、内訳(本体価格・消費税・別途費用の有無)を併記する。
- 「効果」は定量(コスト削減額、工数削減時間など)と定性(品質向上、リスク低減など)を分けて書く。定量が出せない場合は無理に数値化せず、その旨を記す。

```markdown
# 稟議書

- 件名: ◯◯システム導入に関する稟議
- 起案部署・起案者: 企画部 佐藤花子
- 起案日: 2026年◯月◯日
- 決裁区分: 部長決裁 / 事業部長決裁 / 役員決裁 (該当に◯)
- 起案理由(背景): 現行の◯◯業務は手作業により月間◯時間を要しており、繁忙期の遅延が常態化している。
- 内容:
  - 何を: 株式会社サンプル製 ◯◯システムの導入
  - いくらで: 初期費用 ◯◯円、月額費用 ◯◯円
  - いつまでに: 2026年◯月◯日 契約締結、◯月◯日 稼働開始
- 金額(税込・内訳):
  - 初期費用: ◯◯円(税込) うち消費税 ◯◯円
  - 月額費用: ◯◯円(税込)、契約期間 ◯年
  - 別途費用: なし / あり(内容: ◯◯)
- 効果:
  - 定量: 月間作業時間を◯時間から◯時間へ削減見込み
  - 定性: 入力ミスの削減、担当者の属人化解消
- リスクと対策:
  - リスク: 移行期間中の並行運用による負荷増
  - 対策: 移行期間を◯週間設け、旧システムと並行稼働させて検証する
- 添付資料: 見積書、比較表、スケジュール案
```

## 3. 報告書

報告書は目的に応じて「月次報告」と「出張報告」の2形式を使い分ける。

### 3-1. 月次報告

今月の実績・前月比・課題・来月の予定の順で構成する。

```markdown
# 月次報告(2026年◯月分)

- 今月の実績: ◯◯件対応(前月◯◯件)。主要案件は◯◯。
- 前月比: 件数 +◯%、売上 ◯◯円(前月比 +◯◯円)
- 課題: ◯◯の対応に遅れが生じている。原因は◯◯。
- 来月の予定: ◯◯の完了、◯◯の着手
```

### 3-2. 出張報告

目的・日程・訪問先・面談内容・成果・所感・経費概算の順で構成する。

```markdown
# 出張報告

- 目的: 株式会社サンプルとの◯◯に関する打合せ
- 日程: 2026年◯月◯日(◯)〜◯日(◯)
- 訪問先: 株式会社サンプル 大阪支店
- 面談内容: 営業部長 山田太郎 様と◯◯について協議。先方より◯◯の要望あり。
- 成果: ◯◯について合意。次回打合せは◯月予定。
- 所感: ◯◯の点で認識のずれがあったため、次回までに社内で整理が必要。
- 経費概算: 交通費 ◯◯円、宿泊費 ◯◯円、合計 ◯◯円(領収書は別途精算申請)
```
