# jp-bizdoc 敬語チェックリスト

添削は必ず「誤 → 正」の書き換えと「理由」をセットで示す。理由を省いた修正だけの提示はしない。

## NG パターン表(誤 → 正 → 理由)

| # | 誤 | 正 | 理由 |
|---|---|---|---|
| 1 | 了解しました | 承知いたしました | 「了解」は同格・目下向けの表現。目上・社外には謙譲語の「承知いたしました」を使う。 |
| 2 | ご苦労様です | お疲れ様です | 「ご苦労様」は目上から目下へのねぎらいの言葉。目上に対して使うのは不適切で、立場を問わず使える「お疲れ様です」を使う。 |
| 3 | お世話様です | お世話になっております | 「お世話様です」は口語的・略式の表現。社外メール・文書の定型挨拶としては「お世話になっております」を使う。 |
| 4 | おっしゃられる / お伺いさせていただく | おっしゃる / 伺う | 二重敬語。「おっしゃる」自体が尊敬語なのに「れる」を重ねている。「伺う」自体が謙譲語なのに「させていただく」を重ねている。いずれも一つの敬語で足りる。 |
| 5 | (許可・恩恵がない動作への)〜させていただく の乱用 | いたします | 「させていただく」は相手の許可を受けて恩恵を受ける場合に使う謙譲表現。単なる自分の業務動作(報告する・確認する等)には過剰で、「いたします」で十分。 |
| 6 | 部長様 | 部長 / ◯◯様 | 役職名は それ自体が敬称のため「様」を重ねるのは二重敬称。役職のみで呼ぶか、氏名に「様」を付ける。 |
| 7 | 休まさせていただく | 休ませていただく | いわゆる「サ入れ言葉」。五段活用動詞「休む」の使役形は「休ませる」であり、「休まさせる」は誤り。 |
| 8 | とんでもございません | とんでもないことでございます | 「とんでもない」は分解できない一語の形容詞であり、末尾の「ない」だけを「ございません」に置き換えるのは文法的には誤り。ただし近年は「とんでもございません」も慣用表現として広く使われており、辞書・文化庁の見解でも許容が進んでいる。社外の格式ある文書では厳密な形を、口頭・カジュアルな場面では慣用形でも大きな問題にはなりにくい旨を添えて案内する。 |
| 9 | 資料のほうをお送りします | 資料をお送りします | 「〜のほう」は本来、方向・比較対象をぼかす表現。対象が一つしかない場合に付けるのは不要な婉曲表現であり、簡潔に言い切る。 |
| 10 | 弊社の田中がおっしゃった | 弊社の田中が申した | 敬語の方向の誤り。尊敬語は相手側・第三者の動作に使うもので、自社側の人間の動作には謙譲語(申す)を使う。社内の役職者であっても、社外の相手に対して話すときは自社側は立てない。 |
| 11 | 御社 / 貴社 の混同 | 話し言葉は「御社」、書き言葉は「貴社」 | どちらも「あなたの会社」を指す尊敬表現だが、会話・面談などの口頭では「御社」、メール・文書などの書き言葉では「貴社」を使い分けるのが一般的な慣行。 |
| 12 | クッション言葉を省いた依頼・断り文 | 恐れ入りますが / お手数をおかけしますが / 差し支えなければ、を前置きする | 依頼・断り・確認をそのまま伝えると命令的・高圧的な印象を与えやすい。本題の前にクッション言葉を置くことで、相手への配慮を示す。 |

## 社外メールの定型構成

宛名 → 挨拶 → 名乗り → 要旨 → 本文 → 結び → 署名 の順で構成する。

```markdown
株式会社サンプル
営業部 部長 山田太郎 様

お世話になっております。
株式会社◯◯ 企画部の佐藤です。

本日は◯◯の件でご連絡いたしました。

(本文: 用件を簡潔に。依頼・確認事項がある場合はクッション言葉を添える)
お手数をおかけしますが、◯月◯日までにご確認いただけますでしょうか。

引き続きどうぞよろしくお願いいたします。

--
株式会社◯◯ 企画部
佐藤花子
TEL: 000-0000-0000 / Mail: sample@example.com
```

- 宛名: 会社名・部署名・役職・氏名+「様」の順。役職と「様」を重ねない(#6参照)。
- 挨拶: 初回・継続取引ともに「お世話になっております」が基本。
- 名乗り: 自社名+部署名+氏名。初回は簡単な自己紹介を添える。
- 要旨: 本文の前に用件を一行で示すと相手が読みやすい。
- 結び: 具体的な依頼・お願いを含む場合は「ご確認のほど、何卒よろしくお願いいたします」等の「何卒〜」を用いる。継続的な取引・関係の維持を述べる連絡では「引き続きよろしくお願いいたします」を用いる。

## 時候の挨拶(12ヶ月表)

時候の挨拶は儀礼的な書状・案内状・年始年末の挨拶状など、**格式を要する文書**で使う。日常のビジネスメールには通常付けない。

| 月 | 時候の挨拶(例) |
|---|---|
| 1月 | 新春の候 |
| 2月 | 立春の候 |
| 3月 | 早春の候 |
| 4月 | 陽春の候 |
| 5月 | 新緑の候 |
| 6月 | 梅雨の候 |
| 7月 | 盛夏の候 |
| 8月 | 残暑の候 |
| 9月 | 初秋の候 |
| 10月 | 秋涼の候 |
| 11月 | 晩秋の候 |
| 12月 | 師走の候 |

使い方の例: 「拝啓 新緑の候、貴社ますますご清栄のこととお慶び申し上げます。」のように、頭語(拝啓)の直後に置き、相手の会社への祝辞(ご清栄・ご発展など)を続ける。
