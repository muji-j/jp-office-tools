# jp-slides テーマカタログ

内蔵16テーマの一覧。`build --theme <テーマ名>` または コンテンツ JSON の `"theme"` で指定する。全テーマは `python "${CLAUDE_PLUGIN_ROOT}/scripts/jp_slides.py" themes` でも一覧表示できる(`layout`/`bgsig` 付きで出力される)。

v0.6.0 でテーマエンジンを刷新した。旧版は5アーキタイプ(配置骨格が5種類のみ)の薄いテーマだったが、現在は**16テーマそれぞれが異なるモダンなデザイン原型(アーキタイプ)** を持つ。テーマごとに「シグネチャ背景(`bgsig`)」「コンテンツの並べ方(`layout`)」「見出し上のラベル装飾(`kicker`)」「箇条書きの飾り(`bullet`)」「カードの見た目(`card_style`)」の5点が組み合わさって固有の見た目になる。

## シグネチャ背景(bgsig)16種 — テーマごとのモダンアーキタイプ

`bgsig` は表紙(cover)・中扉(section)・本文(message/stats/table/image、`body` variant)で描き分けられる背景装飾のディスパッチキー。テーマの「顔」を決める最大の要素で、以下の16種がある(カッコ内は該当テーマ)。

| bgsig | テーマ | アーキタイプの内容 |
|---|---|---|
| airyrule | 霞 | 縦の細い罫線1本+中扉見出し下の短いアクセント罫線。装飾を抑えたエアリーな余白系 |
| mono | 白磁 | 装飾図形なし。余白とタイポグラフィのみで見せるモノクロ・ポスター系 |
| rail | 石板 | 左側に丸みを帯びたアクセントのレール(帯)。中扉は幅広版のレール |
| panel | 藍 | 表紙・本文は装飾なし(カード側でリッチさを担保)、中扉のみアクセント全面パネル。ベントー(bento)型のダッシュボード配置と組み合わせる既定テーマ |
| diagonal | 常磐 | 対角のフリーフォーム・ウェッジ(切り込み)。表紙/本文/中扉でサイズが変わる対角スプリット系 |
| band | 鉄紺 | 上部の全幅ヘッダーバンド。中扉は全面バンドになる |
| lines | 青碧 | 罫線による画面の比率分割+右側(表紙)/左側(中扉)のカラーフィールド |
| circle | 朱 | 大型のクロップ円+重なる小円。中扉はアクセント全面 |
| ghostnum | 山吹 | 淡色オーバーサイズの「ゴースト数字」(8)を背景に配置するナンバー系 |
| colorblock | 彩層 | バウハウス風の色ブロック(2色の縦・横ブロック)。中扉は上部ブロック+区切り線 |
| glassdark | 墨 | ダーク背景のみ。ネオン感はカードの枠線・アクセント文字色で表現するダークガラス系 |
| horizon | 藍鉄 | 大型楕円のホライズン(地平線)+グロー円。全 variant で共通のラグジュアリーな奥行き系 |
| wave | 桜 | サイン波(オーガニックウェーブ)。中扉は上向きの波になる |
| bottomband | 亜麻 | 下部の波/バンド(ボトムアンカー)。表紙は波、本文/中扉は帯 |
| frame | 藤 | 全周のヘアラインフレーム。中扉は二重フレーム |
| spine | 明朝 | 縦のスパイン罫線(セリフ体との相性を意識した細い1本線)。variant ごとに位置が変わる |

## コンテンツの並べ方(layout)4種

`layout` は `stats` スライドの並べ方(アーキタイプ)を決める(`message`/`table`/`image` は共通レイアウトで、テーマ差は `bgsig`/`kicker`/`bullet`/`card_style` で出る)。

| layout | 該当テーマ(の一部) | 内容 |
|---|---|---|
| bento | 石板・藍・鉄紺・墨・藍鉄 | 先頭の item を大型ヒーローカード、残りを右側の小カード群に並べるベントー(bento)ダッシュボード型 |
| cards | 常磐・青碧・山吹・彩層・桜・亜麻 | 均等サイズのカードを並べる。4枚を超えたら2行に折り返す |
| poster | 白磁・朱 | item が1個なら超特大の数字(オーバーサイズポスター)、複数なら大きな数字を縦に並べる |
| list | 霞・藤・明朝 | value を大きく、label/note を行として罫線区切りで並べるリスト型 |

## stats スライドの使い方

`type: "stats"` は指標(KPI等)をカード/数字で見せるスライド。`items` は `value`(必須)・`label`(必須)・`note`(任意)を持つオブジェクトの配列で、要素数(1〜)に応じてテーマの `layout` が自動でレイアウトを調整する(例: `bento` は先頭の1件を大きく強調)。

```json
{ "type": "stats", "headline": "主要指標の伸び", "items": [
  { "value": "182億", "label": "エネルギー事業", "note": "+18%" },
  { "value": "24億", "label": "SaaS事業", "note": "黒字化" },
  { "value": "97億", "label": "海外事業", "note": "+4%" }
] }
```

- `value`: 大きく表示する数値・語句(必須)。
- `label`: 指標名(必須)。
- `note`: 補足(前年比・注記等。任意。テーマによってピル(丸背景)またはテキストで表示)。
- `items` が空/未指定の場合はエラーになる(`stats` には少なくとも1件必要)。

## その他のノブ(kicker / bullet / card_style)

テーマの見た目を細部まで決める残り3要素。ユーザーが個別に指定するものではなく、テーマ選択に伴って決まる(カスタマイズは下記「カスタマイズの3ノブ」を使う)。

- `kicker`(見出し上のラベル装飾): `pill`(塗りピル) / `pill_outline`(輪郭のみのピル) / `underline`(下線付きテキスト) / `plain`(装飾なしテキスト)。
- `bullet`(箇条書きの飾り、`message` スライド用): `square`(■) / `dash`(—) / `chevron`(▸) / `ring`(○の輪郭) / `number`(連番) / `tick`(短い横棒)。
- `card_style`(カードの見た目、`stats` 等のカード描画用): `plain`(通常カード) / `topstrip`(上部に色帯) / `leftbar`(左に縦バー) / `outline`(輪郭のみ) / `rounded`(角丸強め) / `glass`(枠線+グロー、ダークテーマ向け)。

## カスタマイズの3ノブ

1. `--accent #RRGGBB` : テーマのアクセント色だけを上書き。配色の基調(背景・文字・bgsig・layout 等)はテーマのまま。
2. `--font yu-gothic|biz-ud|yu-mincho|meiryo` : 見出し・本文フォントの上書き。指定可能なのはこの4種のみ(游ゴシック/BIZ UDPGothic/游明朝/メイリオ)。`yu-mincho` は見出しのみ游明朝になり、本文は游ゴシックのまま。
3. `--variant light|dark` : 現在のテーマの明暗をコヒーレントに反転する簡易切替(背景・文字・ルール色をまとめて入れ替える)。ダーク資料の仕上がりを優先する場合は、反転ではなく専用のダークテーマ(墨・藍鉄)を選ぶ方が配色の一貫性が高い(bgsig の `glassdark`/`horizon` はダーク専用に設計されている)。`--variant` はあくまで「急ぎでライト/ダークを試したい」場合の簡易手段と位置づける。

指定したフォントが利用者の PowerPoint 環境に導入されていない場合、PowerPoint 側のフォールバック(既定フォント)で表示される点に注意する(スクリプト側では検知できない)。

## ブランドテンプレート(社内フォーマット)

`--template <既存pptx>` を指定すると、そのファイルの `Presentation` を土台に各スライドを追加する。テンプレートモードでは自動の背景塗り・シグネチャ背景(`bgsig`)の描画を行わず、テンプレート側のマスター・レイアウト・配色をそのまま尊重する。社内配布済みのブランドテンプレートに合わせたい場合はこちらを使う(テーマ・アクセント・フォントの指定は装飾なしのテキスト配置には影響しない点に留意)。

## gallery / overview の使い方

- `gallery [--out-dir <dir>]` : 同一のサンプル内容(月次営業報告の例。`stats` スライドを含む)で16テーマすべてを生成し、`<テーマ名>.pptx` として書き出す。`overview.pptx` も同時に生成される。テーマ選定に迷ったときの比較に使う。
- `overview [--out <path.pptx>]` : 1枚のスライドに16テーマぶんのカード(背景色・アクセントのスウォッチ・テーマ名・ファミリー/layout・bgsig)を4×4で並べた比較シートを単独生成する。
