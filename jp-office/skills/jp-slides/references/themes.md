## アーキタイプ(5種の配置骨格)

テーマごとに固定のレイアウト装飾(アクセント要素の配置)。内容の文字組みは共通で、装飾部分だけが変わる。

| アーキタイプ | 装飾の内容 |
|---|---|
| minimal-centered | タイトル下に細いルール線のみ。装飾を抑えた簡潔なレイアウト |
| accent-bar | タイトル脇に短いアクセントバー(帯) |
| header-band | 上部全幅の帯。ダークテーマでは帯の上に細いアクセントラインが入る |
| sidebar | 左端に縦のアクセント帯。本文はやや右寄せの余白を取る |
| color-block | 左端に2色の縦ブロック(アクセント色 + 第2アクセント/文字色) |

`cover`・`section` スライドは章扉らしい強めの装飾、`message`・`table`・`image` は本文向けの控えめな装飾になる(スクリプト内の `_accent_decor` が種別ごとに描画する)。

## カスタマイズの3ノブ

1. `--accent #RRGGBB` : テーマのアクセント色だけを上書き。配色の基調(背景・文字・アーキタイプ)はテーマのまま。
2. `--font yu-gothic|biz-ud|yu-mincho|meiryo` : 見出し・本文フォントの上書き。指定可能なのはこの4種のみ(游ゴシック/BIZ UDPGothic/游明朝/メイリオ)。`yu-mincho` は見出しのみ游明朝になり、本文は游ゴシックのまま。
3. `--variant light|dark` : 現在のテーマの明暗をコヒーレントに反転する簡易切替(背景・文字・ルール色をまとめて入れ替える)。**ダーク資料の仕上がりを優先する場合は、反転ではなく専用のダークテーマ(墨・藍鉄)を選ぶ方が配色の一貫性が高い。** `--variant` はあくまで「急ぎでライト/ダークを試したい」場合の簡易手段と位置づける。

指定したフォントが利用者の PowerPoint 環境に導入されていない場合、PowerPoint 側のフォールバック(既定フォント)で表示される点に注意する(スクリプト側では検知できない)。

## ブランドテンプレート(社内フォーマット)

`--template <既存pptx>` を指定すると、そのファイルの `Presentation` を土台に各スライドを追加する。テンプレートモードでは自動の背景塗り・アクセント装飾(`_accent_decor`)を描画せず、テンプレート側のマスター・レイアウト・配色をそのまま尊重する。社内配布済みのブランドテンプレートに合わせたい場合はこちらを使う(テーマ・アクセント・フォントの指定は装飾なしのテキスト配置には影響しない点に留意)。

## gallery / overview の使い方

- `gallery [--out-dir <dir>]` : 同一のサンプル内容(月次営業報告の例)で16テーマすべてを生成し、`<テーマ名>.pptx` として書き出す。`overview.pptx` も同時に生成される。テーマ選定に迷ったときの比較に使う。
- `overview [--out <path.pptx>]` : 1枚のスライドに16テーマぶんのカード(背景色・アクセントのスウォッチ・テーマ名・ファミリー/アーキタイプ)を4×4で並べた比較シートを単独生成する。
